# Convert single file to markdown

Convert the provided file to a downloadable markdown format file.

Do not include any image from the source into your export. You can instead embed a readable text representation of each image as feasible. For representing figures, you may embed Latex, tables, Mermaid, or any other suitable readable representation. As a fallback, you may alternatively embed a text description of the image.
